# Voyage
Social Travel & Group Discovery Platform

Built according to Voyage SRS v1.0.

## Stack
- Frontend: React + React Router + Tailwind CSS + Axios + Framer Motion
- Backend: Node.js + Express + MongoDB + Mongoose
- Auth: JWT (OAuth-ready)
- Realtime: Socket.IO
- Recommendation service: Python + FastAPI (later phase)

## Development phases
1. Foundation
2. Core Travel Social Platform
3. Social Layer
4. Recommendations
5. Agency Marketplace
6. Hotels/Food/Routes
